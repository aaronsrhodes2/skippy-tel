MineBench: the home AI builds in blocks

MineBench gives a model a build request and a Minecraft-style grid, and people compare the results side by side. The detail and precision of a build show at a glance what a model can do: shape, proportion, depth, planning.

Here the builder is purple Skippy: the Captain's own coding agent thinking with Skippy Core's local model, on hardware in his house, free to run. Every run uses MineBench's own system prompt and rules: a 256-block grid, the simple palette of 25 blocks, and the voxel.exec tool (JavaScript that places blocks, boxes and lines). The frontier models' builds are on MineBench's own site, for comparison.

Each run below: the build request, the numbers, four views, and the model itself to turn with a finger or a mouse. A run marked "expanded prompt" got a full written specification instead of the benchmark's one line: it shows how far direction lifts a local model, and is not comparable with the leaderboard.
