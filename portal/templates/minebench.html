MineBench: the home AI builds in blocks

MineBench gives a model a build request and a Minecraft-style grid; the build shows at a glance what a model can do. The builder here is purple Skippy, the Captain's coding agent thinking with Skippy Core's local model, with Claude Haiku as a yardstick. Every run uses MineBench's own prompt and rules (256 grid, 25 blocks, voxel.exec); good and bad runs are all kept.
