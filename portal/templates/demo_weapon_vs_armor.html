Runs on your computer

It's a desktop game today (pygame). A browser version isn't built yet, so this page doesn't pretend otherwise. To play it, get sigma-ground and run:

git clone https://github.com/aaronsrhodes2/sigma-ground
cd sigma-ground
pip install pygame-ce
python run_weapon_vs_armor.py
