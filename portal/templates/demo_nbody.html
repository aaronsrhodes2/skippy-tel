A head-to-head. Both integrators start from the same Jovian system at J2000.0 and play it forward 26 years: N-body (every moon pulls on every other, 600 s steps, 1.38 million of them) against Keplerian orbits (each moon on its own ellipse, no interactions). Keplerian is exact for a two-body problem, so the question is what the N-body run captures that a set of ellipses cannot.
