Shifting Prophesy: two models, one game

Two AI models build the same browser game, a top-down adventure with a procedurally generated overworld and dungeons, from the same written spec. Each turn the Captain sends both the same prompt, word for word. They run in the same Claude Code with the same instructions, rails and 131,072-token window; only the model differs. After each turn a referee checks both against the spec on 500 seeds neither can see, takes the same screenshots of both, and the Captain scores them.
